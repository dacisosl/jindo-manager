개인정보처리방침

진도계획표(https://dacisosl.github.io/jindo-manager/)

시행일 2026년 8월 15일

진도계획표는 별도의 서버가 없는 웹 도구입니다. 선생님이 입력한 시간표·진도·일정은 모두 사용하는 브라우저 안에만 저장되며, 운영자를 포함해 누구에게도 전송되지 않습니다.

1. 수집하는 항목

운영자가 수집·보관하는 개인정보는 없습니다. 아래 정보는 이용자의 브라우저 저장소(localStorage)에만 저장됩니다.

  • 학기 기간, 시간표(요일·교시·반 이름), 과목명
  • 차시별 수업 내용, 결손·수행평가 표시
  • 학사일정(휴업일·행사·고사·개인 일정의 날짜와 이름)
  • 화면 설정(글씨 크기, 인쇄 크기, 미니멀 모드 등)
  • 파일 인식 기능을 쓰는 경우 이용자가 직접 입력한 OpenRouter API 키

학생 이름·학번·연락처 등 학생 개인정보는 입력받지도, 저장하지도 않습니다. 반은 "2-1"과 같은 학급 표기만 사용합니다.

2. 이용 목적

  • 시간표와 학사일정을 바탕으로 반별 수업 차시를 계산해 화면에 표시
  • 진도표 인쇄, 데이터 백업(JSON)·내보내기(CSV)
  • 파일 인식: 이용자가 올린 시간표·학사일정 파일에서 내용을 추출

3. 보유 기간과 파기

운영자가 보유하는 정보가 없으므로 별도의 보유 기간이 없습니다. 브라우저에 저장된 정보는 다음의 경우 즉시 파기됩니다.

  • 앱의 설정 > 데이터 > 전체 내용 초기화를 실행한 때
  • 브라우저의 사이트 데이터·쿠키를 삭제한 때

4. 안전조치

  • 모든 접속은 HTTPS로 암호화됩니다.
  • 입력한 내용은 서버로 전송·보관되지 않습니다(파일 인식 기능 제외, 8항 참조).
  • API 키는 브라우저에만 저장되며, 백업 파일(JSON)에 포함되지 않습니다.
  • 콘텐츠 보안 정책(CSP)을 적용해 허용되지 않은 외부 자원의 실행을 차단합니다.
  • 학교 시간표 프리셋은 암호화(AES-256-GCM)해 보관하며, 암호 없이는 열람할 수 없습니다.

5. 정보주체의 권리와 행사 방법

  • 열람·정정: 앱 화면에서 언제든 직접 확인하고 고칠 수 있습니다.
  • 내려받기: 설정 > 데이터 > 전체 데이터 저장(.json)으로 전체 사본을 받을 수 있습니다.
  • 삭제: 설정 > 데이터 > 전체 내용 초기화로 즉시 삭제할 수 있습니다.
  • 그 밖의 요청은 아래 연락처로 문의하실 수 있습니다.

6. 만 14세 미만 아동의 개인정보

본 도구는 교사의 수업 진도 관리를 위한 것으로, 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 학생 개인을 식별할 수 있는 정보를 입력하는 기능이 없으며, 이용자(교사)께서도 학급 표기 외에 학생 개인정보를 입력하지 않으시기 바랍니다.

9. 처리 위탁

개인정보 처리 업무를 위탁하고 있지 않습니다. 8항의 호스팅·파일 인식은 이용자의 요청에 따라 해당 사업자에게 정보가 전달되는 것으로, 별도의 위탁 계약에 따른 처리는 없습니다.

10. 학교 시간표 프리셋에 관한 안내

본 도구에는 해밀고등학교 교사별 시간표 프리셋이 포함되어 있어, 이름 검색으로 시간표를 불러올 수 있습니다. 이 자료에는 교사 성명과 담당 시간표가 포함되므로 학교 공용 암호로 암호화(AES-256-GCM)하여 보관합니다. 암호를 모르면 파일을 내려받아도 내용을 확인할 수 없으며, 암호는 학교 내부에서만 공유됩니다. 게시 중단을 원하시는 선생님은 7항의 연락처로 알려주시면 즉시 삭제해 드립니다.
